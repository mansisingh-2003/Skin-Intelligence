# AI Skin Intelligence & Personalized Skincare Planner

An AI-powered skincare intelligence platform that provides personalized
skin assessments, skincare routines, ingredient analysis, product
recommendations, skin health scoring, and progress tracking.

## Technology Stack

- Python
- FastAPI
- React.js
- PostgreSQL
- Scikit-learn
- Pandas
- NumPy
- JWT
- Docker
- Git/GitHub

## Project Status

Currently under development.

- Milestone 1: Foundation & User Management
- Milestone 2: AI Skin Assessment & Routine Generation
- Milestone 3: Product & Ingredient Intelligence
- Milestone 4: Analytics, Testing & Deployment
